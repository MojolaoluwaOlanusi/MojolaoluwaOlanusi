## 🚀 Featured Projects

### [Tudu](https://github.com/MojolaoluwaOlanusi/Tudu): Collaborative Task Management Platform

![Tudu](https://img.shields.io/badge/STATUS-LIVE-brightgreen?style=flat-square)

Open-source Kanban task manager for individuals and teams, with real-time sync, AI-assisted planning, analytics, and focus tracking. Self-hostable and released under AGPL-3.0.

**Live:** [tudu-kanban.vercel.app](https://tudu-kanban.vercel.app)

- Drag-and-drop Kanban board with live synchronisation via Socket.IO
- Natural-language task input and AI task breakdown (Gemini, Groq, or local Ollama)
- Public REST API (`/api/v1`) with personal access tokens, Zod validation, rate limiting, and signed webhooks
- Pomodoro timer, productivity analytics, shared task lists, and installable PWA with push notifications
- Unit, integration (real PostgreSQL), and Playwright end-to-end tests

**Stack:** React 18, TypeScript, Vite, Tailwind CSS, React Query, Zustand, @dnd-kit, Chart.js · Node.js, Express, PostgreSQL (raw SQL), Socket.IO · Google/GitHub OAuth, JWT · Vercel, Render, Neon

### [Snitch](https://github.com/MojolaoluwaOlanusi/Snitch): Real-Time Social Media Platform

![Snitch](https://img.shields.io/badge/STATUS-LIVE-brightgreen?style=flat-square)

Full-stack social network with real-time chat, algorithmic feeds, group functionality, rich media uploads, and an admin moderation layer.

**Live:** [snitch-social-frontend.vercel.app](https://snitch-social-frontend.vercel.app)

- Real-time messaging with typing indicators, read receipts, and reactions, synchronised across backend instances using Redis Pub/Sub
- Direct browser-to-storage uploads using Cloudflare R2 presigned URLs
- Background job processing with BullMQ; Web Push notifications
- JWT authentication, rate limiting, and full-text search over users, posts, and hashtags
- Separate admin dashboard for moderation, user management, and analytics

**Stack:** React 18, TypeScript, Vite, Tailwind CSS, Zustand, Framer Motion · Node.js, Express, Socket.IO, BullMQ · MongoDB, Redis, Cloudflare R2 · Vercel, Fly.io

### [Reeli](https://github.com/MojolaoluwaOlanusi/Reeli): Movie & TV Discovery Platform

![Reeli](https://img.shields.io/badge/STATUS-LIVE-brightgreen?style=flat-square)

Discovery app that helps users decide what to watch next through rich metadata, watch-provider information, and personalised picks based on their activity.

**Live:** [reeli-movies.vercel.app](https://reeli-movies.vercel.app)

- Personalised "Top Picks" ranking driven by user activity, with regional popularity as a fallback for new users
- Server-side proxy for TMDB requests, keeping API credentials out of the browser
- Per-user data protected by row-level security (Appwrite, Google sign-in)
- Genre browsing, shareable title pages, cast and crew details, trailers, and anime enrichment via AniList GraphQL

**Stack:** React, Vite, React Router, Tailwind CSS · Node.js, Express · TMDB API, AniList GraphQL, Appwrite · Vercel
